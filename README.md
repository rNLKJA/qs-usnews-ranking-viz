# 排名雷达 · Ranking Radar

**Four university-ranking systems, four decades, side by side — see the trend, and where they disagree.**

🔗 **Live:** https://qs-usnews-ranking-viz.vercel.app
📊 **Open dataset:** [`public/data/`](public/data) (CSV · JSON · Frictionless datapackage, CC-BY-4.0)

Ranking Radar is an interactive visualisation that places **3,790+ universities** across **four ranking systems** on a shared timeline, lets you compare any set of schools head-to-head, and shows how whole regions rise and fall over time. All data is pulled live from official endpoints or cited open archives — **nothing is hand-entered**.

---

## Why

QS, U.S. News and Times Higher Education routinely disagree — a university can be top-15 in one and outside the top-30 in another. Ranking Radar makes that disagreement visible at a glance, and turns 40 years of scattered ranking data into a single, explorable, openly-licensed dataset.

---

## Features

### 🧭 Timeline
Rank 1 at the left, universities placed along the axis by their rank for the selected year, with one **lane per ranking system**. Hover any logo for a card with the school's rank in every system plus links to its QS / U.S. News / THE profile. The field streams in as you scroll right; a **spacing slider** controls density and a **year slider** moves through 1984–2027.

### 🔍 Compare (multi-select)
Click any number of schools in the left panel to **isolate just those** on the timeline. The rank axis **rescales to fit them in one window** (no scrolling), and each school gets a colour-coded dashed connector tracing its rank across the systems — so the cross-system disagreement jumps out instantly.

### 🌏 Regions
A line chart of each macro-region's share of the global **top-50 / 100 / 200** over **2011–2026** (Times Higher Education). It tells a real story: North America's share of the top 100 erodes (~58 → ~38) while Asia rises (~8 → ~20) and Europe holds steady.

### 📈 Trend modal
Click a school's logo for its full **rank trend across all four systems** — QS and THE as multi-year lines, U.S. News as points, with a faint bar showing cross-system spread per year — plus the school's location, description, and source links.

## Data

| System | Coverage | Source |
|---|---|---|
| **QS World University Rankings** | **2016–2027** (complete) | topuniversities.com REST endpoint |
| **Times Higher Education** | **2011–2026** (complete) | timeshighereducation.com JSON API |
| **U.S. News National (U.S.)** | **1984–2025** | [Archive of US News College Rankings](https://github.com/frishberg/Archive-of-US-News-College-Rankings) |
| **U.S. News Best Global** | **2026 only** | usnews.com JSON API |

**No hard-coded values.** The dataset is generated by [`scripts/build-dataset.mjs`](scripts/build-dataset.mjs) (`npm run data`), which pulls each system live and matches universities across systems by normalised name. Notable techniques, documented in [`Notes/DATA_PIPELINE.md`](Notes/DATA_PIPELINE.md):

- **QS history** is recovered by harvesting old edition node-ids from the **Wayback Machine** — the live QS endpoint still serves them — and identifying each edition's year by a known-rank fingerprint.
- **THE** exposes a year-parameterised API, giving its full multi-year history.
- **U.S. News Best Global** is the one honest gap: its API serves only the current edition, and no public archive (GitHub or Wayback) holds full historical editions, so it is **current-only and clearly labelled** rather than fabricated.

### Open / FAIR dataset (`public/data/`)
- `universities.csv` — one row per university: id, name, country, region, city, description, profile links.
- `rankings.csv` — tidy long format: `university_id, system, year, rank` (lower = better).
- `universities.json` — the same data nested (consumed by the app).
- `datapackage.json` — [Frictionless](https://frictionlessdata.io/) descriptor with field schemas.
- `LICENSE` — **CC-BY-4.0**.

Findable (stable ids, versioned, datapackage), Accessible (open CSV/JSON over HTTPS), Interoperable (tidy long format, country→region), Reusable (documented provenance + open licence).

## Tech stack

Vite · React 19 · TypeScript · Tailwind CSS v4 · **shadcn/ui** (Radix) · D3 (`d3-scale` / `d3-shape` for maths; React renders the SVG). Design follows a **Nothing OS** aesthetic — flat monochrome, sharp corners, Bitcount / DM Sans type, accent red used sparingly.

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # type-check + production build
npm run data     # regenerate the dataset from live sources (~3–4 min)
```

## Project structure

```
public/data/          generated dataset (CSV · JSON · datapackage · LICENSE)
scripts/build-dataset.mjs   the data pipeline (npm run data)
src/components/       Timeline, TrendModal, RegionalView, Sidebar, UniversityLogo
src/systems.ts        ranking-system config (colours, labels, profile urls)
Notes/DATA_PIPELINE.md   how the data is sourced
```

## Deploy

Zero-config on **Vercel** (auto-detects Vite; build `npm run build`, output `dist/`).
